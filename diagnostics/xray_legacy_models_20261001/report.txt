Compatibility and portable packaging facts
-------------------------------------------
- Directly compatible with current X-ray Crops RTMDet: NO for both legacy
  families. RTMPose emits 25 keypoints; current X-ray RTMDet emits specimen boxes.
  The NumPy crop model emits a single oriented crop geometry, not RTMDet detections.
- Likely roles: RTMPose = Structure/marker; NumPy ridge models = Crop geometry.
- A checkpoint/config/environment set exists for RTMPose in the old project, but
  this snapshot does not establish portable inference without path normalization
  and the matching managed runtime. Training reproducibility is not established;
  datasets and annotations were deliberately excluded.
- Current generic AI package code has landmark and NumPy crop package paths. Current
  X-ray model registration is a separate xray_crop_models contract with checkpoint
  and config paths. The inspected legacy records do not constitute an X-ray RTMDet
  portable package, and no X-ray project/schema was available to verify import.
