# Changelog

## 1.0.0-rc.1 — 2026-10-10

First public release candidate of MorphoLabel for Windows 10/11 x64.

- Introduces two integrated scientific modules: **Landmarks & Measurements** and **X-ray Traits**.
- Supports standardized, stage-by-stage annotation of large collections of photographs and radiographs.
- Provides manual annotation, human verification, repeatability assessment, review queues and quality control.
- Offers optional AI-supported Crop, Landmark and X-ray Structure workflows, including local training, prediction and model exchange.
- Preserves project records, scientific annotation states, correction history and model provenance.
- Exports TPS, CSV, MorphoJ-compatible coordinate data, measurement tables and X-ray traits, with specimen, sample, locality and source-file identities.
- Offers a verified-only Landmarks analysis dataset bundle with omission reports, definitions and data integrity information.
- Includes a Windows installer; optional AI components are installed separately after the user's approval.

**Status:** release candidate for external evaluation. Stable 1.0.0 has not been published.
