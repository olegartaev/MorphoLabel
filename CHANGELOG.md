# Changelog

## 1.0.0-rc.1 — 2026-10-10

Consolidated public release candidate for MorphoLabel 1.0.

- Provides one modular Windows application with Landmarks & Measurements and X-ray Traits workflows.
- Supports stage-by-stage processing of large biological image collections, with manual annotation and optional AI assistance.
- Includes human verification, review queues, human repeatability, quality control, training and portable model exchange.
- Preserves research provenance, correction history, schema/model compatibility and verified scientific project data.
- Exports Landmarks, Measurements and X-ray Traits with specimen, sample, locality and source-file identities.
- Includes TPS, CSV, MorphoJ-compatible exports and consistent analysis bundles with QC, omissions and manifest checksums.
- Offers resumable, verified first-run AI component setup, hardware qualification and offline project processing.
- Provides a concise Export interface, scientific terminology, independent module attribution and optional external AI-assistant help.
- Windows installer and AI assets must pass hosted distribution and installed-application acceptance before publication.

The original October 6–10 prereleases were developmental validation builds and are superseded by this consolidated candidate. Historical changes remain available in the repository's commit history.
